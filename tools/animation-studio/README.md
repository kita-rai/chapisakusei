# イラスト・モーション工房

一枚のイラストを、骨格・部位の範囲を確認しながら動かすローカル編集アプリです。画像・推論結果を外部へ送信しません。WebGL2のメッシュ描画、階層リグ、二骨IK、固定刻みのspringを共通エンジンにしています。

## Windowsで起動

1. `Illust-Motion-Studio-Windows.zip` をフォルダーへ**すべて解凍**します。
2. `START.cmd` をダブルクリックします。ChromeまたはEdgeで編集画面が開きます。
3. 終了時は起動した黒い画面も閉じます。

Node実行ファイルと解析モデルを同梱しているため、npmの導入・モデルの追加ダウンロードは不要です。画面の場所は `http://127.0.0.1:4173`。起動し直しても同じURLを使うため自動保存が復元できます。ZIP内のindex.htmlを直接開く方法では動作しません。対応対象はWindows x64／現行Chrome・Edge／WebGL2。Windows ARMや32bit向けではありません。

この配布物はブラウザとローカル起動プログラムを使う版です。Tauriデスクトップのソースと保存処理は含みますが、WindowsネイティブEXEのビルド・実機確認は完了していません。

## 操作

- **画像をひらく**：D&D、Ctrl+Vにも対応。自動解析後、骨格点をドラッグして合わせます。認識できない絵は全身／上半身の候補から手動で続けられます。
- **範囲を整える**：「骨格から部位を生成」。右の部位を選んで塗る／消す。Alt＋クリックで人物内の解析点、Alt＋Shift＋クリックで背景の点を指定して「人物範囲を解析」を使えます。
- **動きをつける**：プリセットを選んで再生。手首・足首をドラッグするとIK、胴体なら全身移動。髪・裾を追加して塗り、柔らかさとAlt＋クリックの支点を調整します。胸の揺れは胴体メッシュ内の局所変形です。
- **背景を整える**：単純背景は高速補完、複雑背景はLaMa。修復範囲・保護範囲を塗れます。Alt＋クリックで元位置を指定した複製ブラシも使えます。「隠れた胴体を補完」は肩・腰から推定した胴体内を補完する候補で、元の腕の下の絵を復元する操作です。
- **保存／出力**：`.imotion` に原画像、編集画像、骨格、部位、補完、動作を保存。MP4・PNG連番は固定FPS、WebMは実時間録画です。MP4はブラウザのH.264エンコーダーを使い、非対応の環境ではPNG連番／WebMを使います。固定版FFmpeg同梱のネイティブ出力は未実装です。

ホイール＝拡大縮小／中ボタンまたはSpace＋ドラッグ＝移動／Ctrl+Z＝戻す／Ctrl+Shift+Z＝やり直す／Ctrl+S＝保存。サンプルボタンと `examples/sample.imotion` ですぐ試せます。再生の停止では現在の形を保持し、「原姿勢」で元へ戻します。部位の左右は人物本人基準です。

## 品質と範囲

対象は一人の人物、元の視点を保った小〜中程度の動作です。見えていない面、大きな回転、指・表情・口パクの自動生成は対象外です。写真向け姿勢モデルを候補に使うため、アニメ絵・座位・重なった手足・極端なデフォルメでは点と範囲の修正が必要です。多様なアニメ絵30枚の精度評価は未実施です。

画像投入時は長辺2048px以内の編集画像を作ります。元ファイルもプロジェクトに保持しますが、出力解像度は編集画像の解像度までです。複雑背景の補完は512px推論結果を修復領域だけに合成します。髪先や主線にはブラシ調整が必要な場合があります。LaMa/SAMのCPU処理は端末によって数十秒〜数分かかり、中止ボタンで停止できます。

自動保存はブラウザ内の直近一件です。明示的なプロジェクト保存も行ってください。バージョン互換性のない／破損したファイルの読込み失敗時は編集中のプロジェクトを維持します。v6 JSONは画像・マスク・骨格・手動変形を移行し、動作・親子同期は新方式で再設定します。

## 開発

Node 22以上を使います。配布ZIPの `dist/models` を `public/models` にコピーするか、以下のモデル準備コマンドを実行します。

```sh
npm ci
npm run models:download
npm test
npm run build
npm start
```

`npm run dev` は開発サーバー。モデルは `MODEL_MANIFEST.json` のSHA-256で版を照合します。ブラウザ統合テストはPlaywrightとChromiumを使い、`CHROME_PATH` または実行環境の `/tmp/animator-chrome` を参照します。今回の検証記録は `TEST_REPORT.md`、設計の正本は `DESIGN_REVIEW.md`、短い継続用メモは `PROJECT_STATE.md`。

Windows TauriビルドはRust・Windows SDK・WebView2対応環境で `npm run desktop:build`。ネイティブ配布の合格判定にはWindows実機検証が残っています。
