# 動作確認記録 — 2026-10-02

Linux上のChromium 143、1440×960、ANGLE SwiftShader（ソフトウェア描画）を使用。productionビルドを実際のローカルHTTP起動プログラムで配信した。Windowsそのものの動作確認ではない。

| 対象 | 結果・確認内容 |
|---|---|
| TypeScript/Vite | 型検査とproductionビルド成功 |
| コアテスト | 9件成功：行列、rest、IK長さ、階層同期、接地、FPSに依存しないspring/seek、穴・島のmesh/weights、空mask、破損schema |
| 原姿勢再合成 | サンプル480,000画素でRGB平均絶対誤差0.00045／255。関節補正がbind poseを変えていた問題を修正 |
| 再生 | サンプル1097頂点、ソフトウェアGPUで約60fps。これは特定サンプルの値で、全イラストの性能保証ではない |
| MediaPipe | 公式テスト写真で13関節の候補・人物maskを取得。簡易イラストは未認識を表示し手動編集へ継続 |
| MobileSAM | 同梱ONNXの入力形状を実モデルで確認し、人物範囲を生成。モデル内正規化との二重正規化を修正 |
| LaMa | 同梱fp32モデルで512×512背景推論・局所合成成功 |
| 編集 | 手首を実ドラッグし目標との誤差1px未満、UndoでIKを解除。範囲ブラシの変更とUndoを確認 |
| 保存 | 全part mask/rig/timeのroundtrip一致。原画像、隠れ胴体素材、補完mask、解析点の復元確認 |
| エラー・中止 | モデル処理を中止してmask維持。破損ZIP読込み後も開いていたdocument ID維持 |
| オフライン | ブラウザの外部リクエストを遮断した状態でサンプル編集・PNG/連番/MP4/保存成功 |
| PNG連番 | 1秒30枚をZIP保存、実ファイル数・寸法を確認 |
| MP4 | H.264、600×800、30fps、30フレーム、1.000000秒。ffprobeでファイルを検査 |
| UI | 日本語フォント同梱、画面スクリーンショットを目視確認 |

実行対象：`npm test`、`tests/browser.mjs`（モデル・動画）、`tests/workflow.mjs`（画像投入・直接操作・素材保存）、`tests/smoke.mjs`（外部遮断・修復耐性・出力）。簡易イラストと公式pose写真の少数確認であり、アニメ絵の認識率は測定していない。ONNXのGPU失敗経路はCPUへ再試行するが、すべてのGPU機種の確認ではない。

残る出荷条件：Windows実機、Tauriのビルド・起動、ネイティブ固定encoder、実イラストの品質コーパス、隠れ胴体の多様な遮蔽品質、低スペック機のメモリ計測。TauriクロスビルドはMicrosoft SDK配布元への接続ができず停止した。
