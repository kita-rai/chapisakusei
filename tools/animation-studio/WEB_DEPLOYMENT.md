# Web配信

GitHub Pagesの既存 main / root 配信を維持し、`animation/` にビルド済みファイルを置く。トップからのリンクは外し、編集ページに `noindex,nofollow,noarchive` を指定する。URLと公開ソースは閲覧可能であり、認証による非公開ではない。

PC版Chrome/Edgeを推奨。初回はモデルと実行用WASMをダウンロードし、推論・画像処理・動画生成はブラウザ内で実行する。画像をアップロードするAPIや外部解析サービスはない。全機能のオフライン起動は保証しない。自動保存はブラウザのIndexedDB。プロジェクト保存で端末にバックアップできる。

モデルの原ファイルは MODEL_MANIFEST.json のSHA256とサイズを照合する。LaMaは単一ファイルがGitHub制限を超えるため40MiB以下へ分割。ファイル名にモデルhashを含め、Cache APIは保存容量不足でも処理を続行する。取得中は中止可能。

更新は `animation-studio` branchへソースを反映しBuild animation pageを実行。生成された配信ファイルを含めたcommitを確認してmainへ統合する。モンスト等の既存ページを再生成しない。

アニメ絵30枚以上の品質評価は未完了。大きな姿勢変更・裏面生成・指・表情は対象外。AI補完は候補のため、範囲・輪郭・重なりの手動確認が必要。
