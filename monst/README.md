# SHOT LAB — GitHub Pages edition

前回作成した SHOT LAB の24課題版を引き継いだ、非公式の反射理論教材です。
元コードのコミット: `6e8071d5e2564ab6d60bcef69bddb687734a6177`。

## 改良内容

- 24課題、自由配置、1024段階と連続角度、段差と円の判定モデルを維持。
- 反射・接触点を選ぶ再生、前後の接触点への移動、最初から再生。
- 全画面内の終了・角度調整・発射・再生・やり直し操作。
- 課題の前後移動、最後に開いた課題の再開。
- 進捗と保存済み自由盤面のJSON書き出し・読み込み。
- ドラッグで次を打つ際の前軌道保持、軌道予測のキャッシュ。
- chapisakusei の一覧への戻りリンク。

## データ

進捗・最後の課題・保存済み自由盤面は localStorage に保存します。
アカウント別の保存や端末間の自動同期は実装していません。
旧サイトとGitHub Pagesではオリジンが違うため、旧サイトの進捗は自動移行されません。
読み込みでは既存の達成状況に合算し、盤面を含む場合は保存済み盤面を置き換えます。

## 検証

このディレクトリで実行:

```sh
node checks/verify.mjs
node checks/storage.mjs
node --check app.mjs
```

24課題の到達可能性・達成判定、敵/弱点/ブロック判定、ループ、隙間への進入、ドラッグ、再生、追加操作と保存データの検証を含みます。
DOM・Canvasの自動検証はモックを用います。実ブラウザでのレイアウトやネイティブ全画面APIの確認を代替するものではありません。

物理・1024段階の角度・判定形状は教材モデルで、本家の内部仕様を保証しません。参考資料はページ内の「モデルの範囲・参考資料」に記載しています。
